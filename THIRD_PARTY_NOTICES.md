## ⚠ Commercial-license blocker: NRLMSIS 2.1

**NRLMSIS 2.1 must be removed from the build — or written consent obtained from
NRL — before Polaris's first commercial license is sold.**

NRLMSIS is governed by NRL's *MSIS® Open Source Academic Research License
Agreement*, which grants use "solely for research, academic, and non-profit
purposes" and states that "any commercial use is prohibited." Clause 4a further
bars selling, licensing, or transferring for a fee the software, **any derivative
work, or any data products generated by the software**, absent written consent
from NRL IP Counsel.

Polaris's noncommercial tier ([`LICENSE`](LICENSE), PolyForm Noncommercial 1.0.0)
sits comfortably inside those terms — the project is research software today. The
conflict is specifically with the **paid commercial tier** described in
[`LICENSING.md`](LICENSING.md): selling a Polaris commercial license, while
Polaris incorporates MSIS, would be licensing a derivative work of MSIS for a fee.

The integration is built so that removal is cheap, and it should stay that way:

- **The source is fetched, never committed.** `cmake/Dependencies.cmake` pulls the
  upstream tarball at configure time under a pinned SHA256. Nothing of NRL's
  enters git history, so removing it is deleting that block plus
  `sim/world/nrlmsis.{hpp,cpp}` and `sim/world/msis_shim.F90` — not a history
  rewrite.
- **The build degrades cleanly.** `-DPOLARIS_BUILD_NRLMSIS=OFF` (or simply no
  Fortran compiler) drops the model; the sim falls back to the exponential
  atmosphere in `sim/world/atmosphere.hpp` and the whole suite still builds and
  passes.
- **No MSIS-generated data is committed.** The golden test
  (`tests/unit/sim_world_nrlmsis_test.cpp`) validates against upstream's *own*
  shipped `msis2.1_test_ref_dp.txt` read from the fetched tree. A fixture we
  generated would be a "data product" under clause 4a and would outlive the
  model's removal — so do not create one.
- **NRL's sources are never edited.** The C interop layer is Polaris's own
  `sim/world/msis_shim.F90`, which only calls the published interface. Modifying
  the model itself would trigger clause 4b (deliver changes to NRL Code 7630 and
  publish them).

### Required notice

Per clause 4c, any package incorporating MSIS must carry this statement:

> This software incorporates the MSIS® empirical atmospheric model software
> designed and provided by NRL. Use is governed by the Open Source Academic
> Research License Agreement contained in the file `nrlmsis2.1_license.txt`.

That file ships inside the fetched upstream tarball and is reproduced verbatim
in the build tree at `_deps/nrlmsis-src/nrlmsis2.1_license..txt`. MSIS® is a
registered trademark of the U.S. Government as represented by the Secretary of
the Navy.
