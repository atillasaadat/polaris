## Attribution requirements

- Retain upstream `LICENSE`/`NOTICE`/copyright headers for any vendored or
  redistributed component.
- Each algorithm/model in code cites its primary reference in `docs/refs.bib`
  (design doc §21.1 / Golden Rule 7), independent of these license notices.
- Generated golden fixtures record the GMAT version and the EOP/leap-second/DE
  file identities used, per fixture (design doc §23.1 provenance).

> This file is maintained as dependencies are added. When a "planned" component is
> integrated, update its status and verify the recorded license against the
> upstream `LICENSE` at the pinned version.
