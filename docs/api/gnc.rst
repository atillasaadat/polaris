GNC — ``polaris::gnc``
======================

Estimation, guidance, and control algorithms shared by the FSW and the analysis side (design doc §8). Phase 4 starts with the **coarse attitude chain**: the deterministic **TRIAD** single-frame initializer and the **SS+MAG+IMU coarse estimator** that stands behind the Safe-mode floor (§8.1, §10) — star-tracker- and table-independent, since the analytic Sun ephemeris (§11.3) always answers. The **fine mode** sits alongside it: **Davenport's q-method** for an optimal attitude from any number of weighted vector pairs (cold start and re-init only), and the 6-state **MEKF** estimating attitude error and gyro bias with per-update NIS gating and NEES/NIS consistency diagnostics. Alongside the estimators sits the first of the §8.1 **on-orbit calibrations**: an attitude-free magnetometer hard/soft-iron fit, a streaming ten-parameter ellipsoid least-squares against the onboard IGRF field *magnitude*, which needs no attitude solution and so runs from Safe mode on an uncalibrated vehicle. Beside it sits the second item of the same roadmap, the **Earth-albedo correction** of the sun vector — a *model* rather than a commanded calibration, since it needs geometry and not collected data, so it runs on every cycle whose geometry supports it and refuses (leaving the measurement untouched) on every cycle it does not. Pure math on the canonical ``EstimatedState``: no F´ types and no I/O, so the F´ ``AttitudeEstimator`` component is a thin wrapper.
