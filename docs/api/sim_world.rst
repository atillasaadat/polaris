Environment models — ``polaris::sim::world``
============================================

The forces, torques, and fields of the orbital environment (design doc §5.2) plus the loaders for the committed reference data they consume (§3.7): EGM2008 gravity, third-body, drag (exponential/NRLMSIS + space weather), SRP + eclipse, IGRF, and the EOP/ephemeris tables.
